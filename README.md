# Atlan Mech — мод для Minecraft Java (Fabric 1.21.1)

Гигантский костюм-мех Атлан высотой 7 блоков. Две версии: Mark 42 и Mark 85.

## Структура
Весь код — один файл `src/main/java/com/atlanmod/AtlanMod.java` (остальные классы — вложенные внутри него).
Текстуры, lang, рецепты и fabric.mod.json лежат отдельно в `src/main/resources/`.

## Сборка
JDK 21 + Gradle:
    gradle wrapper --gradle-version 8.10.2
    ./gradlew build        # jar в build/libs/
    ./gradlew runClient    # тест в игре
Jar + Fabric API 0.115.0+1.21.1 в папку mods/.

## Вызов
- Дуговой реактор (золото, редстоун, алмаз, незерит) → Mark 42: детали прилетают издалека и собираются вокруг тебя.
- Нано-реактор (дуговой реактор + 4 незерита + 2 звезды Незера + 2 алмазных блока) → Mark 85: костюм мгновенно собирается из наночастиц.
- ПКМ — вызвать, Shift+ПКМ — автономный режим вкл/выкл. У игрока один костюм: другая версия заменяет прежнюю.

## Управление внутри (обе версии)
WASD+мышь; ЛКМ — кулак (или удар мечом); C — пластинчатый меч (вытягивается на ~14 блоков);
V — полёт СКВОЗЬ БЛОКИ; B — репульсор; N — юнибим (Mk85: усиленный луч гаунтлета);
R — удар по земле; G — прыжок; X — выйти (автономный режим).

## Только Mark 85 (способности Mark 50)
Z — нано-щит (урон -75%, медленнее ход); H — нано-молот (удар по площади с молниями);
M — залп из крыльев (6 выстрелов по ближайшим врагам). Репульсор мощнее, луч сильнее.

## Полёт сквозь блоки
В полёте костюм проходит сквозь блоки, пилот не получает урон от удушья. Приземлиться внутри блоков нельзя.
Если костюм оказался внутри блоков (в т.ч. после сборки), он сам включает полёт, чтобы выбраться.

## HUD и свечение
Внутри костюма слева на экране: здоровье костюма, статусы (полёт, меч, щит) и полоски кулдаунов способностей
с актуальными клавишами. Грудь, глаза, ладони, клинок и двигатель светятся (Mk42 — оранжевым, Mk85 — голубым)
и вспыхивают ярче при выстрелах, ударах, зарядке луча и сборке.

## Что подкрутить
Баланс — константы в entity/AtlanEntity.java; рост — HEIGHT там же; текстуры — assets/atlan/textures/.
